# Ejercicios de Algoritmia — Trayecto 1

Repositorio con los ejercicios y diagramas de flujo desarrollados en PSeInt durante las tres primeras semanas del módulo.

## Estructura del repositorio

* **[Algoritmia-S1](./Algoritmia-S1/)**: Fundamentos, variables, operadores y entradas/salidas.
  * `saludo.psc`, `EdadEnDias.psc`, `PromedioNotas.psc`, `propinas.psc`, `tinto.md` y carpeta `Diagramas/`.
* **[Algoritmia-S2](./Algoritmia-S2/)**: Estructuras condicionales simples, dobles y anidadas (`Si-Entonces`, `Segun`).
  * `Bisiesto.psc`, `parqueadero.psc`, `Semaforo.psc`, `validarEdad.psc` y `validarRegistro.psc`.
* **[Algoritmia-S3](./Algoritmia-S3/)**: Ciclos (`Para`, `Mientras`, `Repetir`) y validaciones iterativas.
  * `CajeroParqueadero.psc`, `Calificaciones.psc`, `FacturaRestaurante.psc`, `Piramide.psc` y `ValidarPin.psc`.
